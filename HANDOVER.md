# talentbylee.com — Handover Context

Personal digital CV for Lee Sam. Live at **https://talentbylee.com** (also `www.talentbylee.com` and `leesam.pages.dev`).

---

## The site

A single-file static site (`index.html`): all CSS and JavaScript inline, no framework, no runtime dependencies. `assets/` holds images only.

`index.html` was generated by `tools/site/build.mjs` from `tools/site/page.html` (layout, styles, scripts) plus the content arrays in `build.mjs` (roles, projects, photos) and the map paths from `tools/gen-maps.mjs`. **Small edits can go straight into `index.html`.** For structural changes, edit `page.html` / `build.mjs` and rebuild (`node tools/site/build.mjs index.html`, which reads `../geo/maps.json` — regenerate that with `tools/gen-maps.mjs` if needed and adjust the path in `build.mjs`). Don't do both without syncing, or the generator goes stale.

**Deploy:** the Cloudflare Pages project `leesam` is connected to GitHub (`builtbylee/leesam`). Pushing to `main` triggers a production build (usually live within a minute, occasionally a few). Check with:
```bash
npx wrangler pages deployment list --project-name leesam
```

## Design: "The thread" (September 2026)

**The idea.** A career told as one continuous line. A single cobalt thread starts at 2007 and runs down the page, drawn as the reader scrolls: through every company in order, through the results and the projects, and ends in a dot above "Let's talk." Nodes light up as the line reaches each chapter and section. Light theme (Lee prefers light), clean and professional; one accent.

Earlier the same day two other directions were shipped and replaced: a dark "Star search" night sky (rejected: Lee prefers light) and its light recolour (rejected: too close to the previous structure). This version changes the structure, not just the surface.

| Token | Value | Use |
|---|---|---|
| `--bg` / `--bg-2` | `#ffffff` / `#f4f5f7` | Page / alternate section ground |
| `--ink` / `--ink-2` | `#0e1116` / `#394150` | Text / secondary text |
| `--muted` | `#5f6775` | Labels, captions |
| `--line` / `--line-2` | `#e6e8ec` / `#d4d8df` | Hairlines, borders, the thread's dotted route |
| `--accent` | `#2f45ff` | The thread, nodes, current nav, key figures, primary button |
| `--accent-ink` / `--accent-soft` | `#2336e0` / `#eef0ff` | Accent text / soft accent fills |
| `--land` | `#d3dae6` | Map land dots |

**Type:** `Epilogue` (700–800) for display and figures; `Hanken Grotesk` for text; `Spline Sans Mono` for years, dates and small labels.

**Motion:** easing `--out` `cubic-bezier(.16,1,.3,1)` for everything that moves; `--spring` for small landings (buttons). Hero: headline words rise from masks, then a hand-drawn loop draws around "AI era.", the portrait unveils. Scroll: the thread draws to 62% of the viewport, with a pen dot at its tip; sections fade up once. Moments: year odometer rolls, count-up to 3,329, FY bars grow, the women-in-management line draws with its points, map routes draw in. Ambient: map lights travel routes while visible, the end dot pings. Reduced motion: the thread is fully drawn, everything visible, no auto-cycling.

## Page structure

| Anchor | Section | Notes |
|---|---|---|
| `#top` | Hero | Kicker, "Lee Sam", headline with loop, thesis, facts, "Follow the line from 2007", portrait. |
| `#career` | 01 Career | Sticky year odometer (desktop) beside chapters in chronological order. Each `.chapter` = company head + `.role` blocks (`data-year` drives the odometer) with summary, three proofs, and a `<details>` for responsibilities and note. |
| `#results` | 02 Results | 3,329 count-up + FY bars · four figures · markets panel (EMEA map + chips) · women-in-management panel (line chart + 2018 vs 2025 rows) · How · Maple Leaf Award. |
| `#built` | 03 Built with AI | Horizontal rail of 7 cards (scroll, drag, arrows, keyboard). Screens cycle on hover; tap steps through. |
| `#beyond` | 04 Beyond work | Text, world route map, 9 photo tiles; choosing a tile lights its route. |
| `#contact` | Contact | End of the thread, "Let's talk.", email, Copy email, Back to top. |

The thread is an SVG inside `.journey`, rebuilt from element positions on load, font load, resize and any size change (ResizeObserver), so opening a `<details>` keeps nodes aligned. Nodes come from `[data-node]` elements.

## Data notes

- Role content lives in `tools/site/build.mjs` (and is rendered into `index.html`). Cloudflare's three roles are ordered 2018 → 2022 → 2026.
- Women-in-management series (2018–2025): 13.0, 13.0, 15.0, 16.0, 16.0, 23.5, 29.2, 29.4 — in the line-chart script.
- Representation rows use `--a` / `--b` (/ `--m`) on a 0–40% axis (position = percentage × 2.5).
- Maps: EMEA Mercator 600×516 (land-50m, 8px grid); world Natural Earth 720×321 (land-110m, 7px grid). Node positions are in the scripts; `tools/gen-maps.mjs` prints them.

## Visual testing

Test at 1440, 430, 390 and 360 widths before every push: no horizontal overflow, no console errors, every `[data-reveal]` reaches `.in` when scrolled through, the thread's drawn length grows with scroll and the end dot lights at the bottom, odometer years change, details open, market chips and photo tiles light exactly one route and label, rail arrows/drag, Copy email, and a reduced-motion pass. Any local Playwright install works; use `scrollTo({ behavior: 'instant' })` when measuring (the page uses smooth scrolling).
